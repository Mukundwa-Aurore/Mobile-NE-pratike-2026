Home Architecture Pages & Endpoints Data Flow

Activity 1 — Word Search & API Integration

User submits a word → validation → API request → parse → store → navigate.

sequenceDiagram
  actor User
  participant UI as Search Screen
  participant Valid as validation.ts
  participant Ctx as DictionaryContext
  participant Cache as dictionaryCache
  participant API as dictionaryApi (axios)
  participant Remote as Free Dictionary API

  User->>UI: Enter word & tap Search
  UI->>Valid: validateSearchWord(input)
  alt invalid input
    Valid-->>UI: error message
  else valid input
    Valid-->>UI: ok
    UI->>Ctx: searchWord(word)
    Ctx->>Ctx: setLoading(true)
    Ctx->>Cache: getCachedDefinition(word)
    alt cache hit
      Cache-->>Ctx: DictionaryEntry[]
    else cache miss
      Ctx->>API: fetchWordDefinition(word)
      API->>Remote: GET /entries/en/{word}
      alt 200 OK
        Remote-->>API: JSON array
        API->>Cache: setCachedDefinition(word, data)
        API-->>Ctx: DictionaryEntry[]
      else 404
        Remote-->>API: Not found
        API-->>Ctx: DictionaryError (not_found)
      else network failure
        Remote-->>API: Error
        API-->>Ctx: DictionaryError (network)
      end
    end
    Ctx->>Ctx: setLoading(false)
    alt success
      Ctx->>Ctx: setEntries(data)
      Ctx-->>UI: navigate word-details
    else not found
      Ctx-->>UI: navigate not-found
    else other error
      Ctx-->>UI: show error on Home
    end
  end

Activity 2 & 3 — Word Display & Pronunciation

Word details screen reads context state and renders definitions with optional audio playback.

flowchart TD
  Entries["DictionaryContext.entries"] --> WD["word-details.tsx"]
  WD --> Parse["dictionaryApi helpers\ngetAllPhoneticTexts\ngetPhoneticAudioEntries"]
  Parse --> Display["Render UI"]
  Display --> Word["Word title + meta"]
  Display --> Phon["WordPhonetics\n(or 'not available')"]
  Display --> Defs["DefinitionSection cards\nparts of speech, examples"]
  Display --> Audio["PronunciationButton\nif audio URLs exist"]

  Audio --> Player["AudioPlayerContext"]
  Player --> AV["expo-av Sound"]
  AV --> CDN["Remote audio URL"]

  UserPlay["User taps Play"] --> Player
  UserPause["User taps Pause"] --> Player
  UserStop["User taps Stop"] --> Player

  Player --> States["States: idle · playing · paused"]

Activity 4 — Drawer & Search History

Successful searches are saved locally; drawer lists history without duplicates.

sequenceDiagram
  actor User
  participant Ctx as DictionaryContext
  participant Hist as SearchHistoryContext
  participant Store as AsyncStorage
  participant Drawer as CustomDrawerContent

  Note over Ctx,Hist: After successful API response
  Ctx->>Hist: addToHistory(entry)
  Hist->>Hist: Remove duplicate word
  Hist->>Hist: Prepend new item (word, POS, preview, timestamp)
  Hist->>Store: persist HISTORY_KEY

  User->>Drawer: Open drawer (menu icon)
  Drawer->>Hist: read history[]
  Hist-->>Drawer: SearchHistoryItem[]
  Drawer-->>User: Display history list

  User->>Drawer: Tap history word
  Drawer->>Ctx: searchWord(word)
  Note over Ctx: Triggers new API lookup (or cache hit)

  User->>Drawer: Clear all (with confirm)
  Drawer->>Hist: clearHistory()
  Hist->>Store: remove / empty array

Activity 5 — Error Handling & User Feedback

Graceful handling of empty input, 404, network errors, and malformed responses.

flowchart TD
  Start["searchWord() called"] --> Empty{Word empty?}
  Empty -->|yes| E1["Set error message\nStay on screen"]
  Empty -->|no| Load["setLoading(true)\nClear previous entries"]

  Load --> Fetch["fetchWordDefinition()"]
  Fetch --> CacheCheck{Cache hit?}
  CacheCheck -->|yes| Success["setEntries(data)"]
  CacheCheck -->|no| HTTP["axios GET request"]

  HTTP --> Status{Response?}
  Status -->|"200 + valid JSON array"| Success
  Status -->|404| NF["DictionaryError not_found\nNavigate not-found screen"]
  Status -->|no response| NET["DictionaryError network\nShow error + Retry"]
  Status -->|invalid / empty array| UNK["DictionaryError unknown\nShow error + Retry"]

  Success --> Hist["addToHistory()"]
  Hist --> Nav["Navigate word-details"]
  Fetch --> Finally["setLoading(false)"]
  NF --> Finally
  NET --> Finally
  UNK --> Finally
